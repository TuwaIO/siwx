# SIWX Documentation Site (`@tuwaio/siwx-docs`)

> Official documentation for the **`@tuwaio/siwx`** ecosystem, available at **[siwx.docs.tuwa.io](https://siwx.docs.tuwa.io)**.

## About This Project

Houses the official documentation for `@tuwaio/siwx` — Low-Level Core & Adapters Layer (L1/L2) of the TUWA Ecosystem. Built with **Next.js 16** and **Nextra 4** (`nextra-theme-docs`).

Documentation covers all packages: `siwx-core`, `siwx-evm`, `siwx-solana`, `siwx-react`, and `siwx-server`.

---

## 🛠 Tech Stack

- **Framework**: Next.js 16+
- **Documentation Theme**: Nextra 4+ (`nextra`, `nextra-theme-docs`)
- **Styling**: Tailwind CSS 4+
- **Client-Side Search**: Pagefind (integrated via `postbuild` script)
- **API Reference Generation**: TypeDoc + `typedoc-plugin-markdown`

---

## 🚀 Getting Started

Run from the **monorepo root**:

```bash
# Install all workspace dependencies
pnpm install

# Start the docs dev server
pnpm --filter @tuwaio/siwx-docs dev
```

Available at **[http://localhost:3000](http://localhost:3000)**.

---

## ✍️ Content Structure

```
src/content/
├── _meta.tsx           # Sidebar navigation config
├── index.mdx           # Introduction page
└── apiReference/       # Auto-generated by TypeDoc (pnpm docs:gen)
    └── _meta.tsx       # Auto-copied by docs:gen script
```

### Regenerate API Reference

```bash
pnpm docs:gen
```

This runs `typedoc` against all package entry points and copies the `_meta.tsx` to the `apiReference/` directory.

---

## 🚀 Deployment

Automatically deployed to Vercel.

- **Production URL:** [**https://siwx.docs.tuwa.io**](https://siwx.docs.tuwa.io)
- Search index is generated by **Pagefind** during the `postbuild` step.
