# Пакети

SIWX складається з одного основного пакета, незалежного від мереж (**L1**), і чотирьох побудованих на ньому пакетів **L2**: адаптерів для кожної платформи блокчейнів (EVM, Solana), прив’язок React і серверних утиліт. Встановіть основний пакет і лише ті пакети L2, які потрібні вашому застосунку. Пакети L2 оголошують `@tuwaio/siwx-core` і свої Web3-бібліотеки чи бібліотеки фреймворків як peer-залежності, тож ваш застосунок тримає лише одну копію `viem`, `@wagmi/core`, `@solana/kit`, `react` чи `zustand`.

Сторінка кожного пакета починається з README пакета (того самого тексту, що опубліковано в npm), за яким іде повний список його експортів. Сторінку кожної функції, класу, типу й константи згенеровано з вихідного коду TypeScript та його JSDoc, тож довідник завжди відповідає випущеному коду. README пакетів і довідник подано англійською.
