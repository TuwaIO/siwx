**SIWX** (Sign-In With X) is the authentication project of TUWA Stage 1: headless, framework-agnostic sign-in for EVM and Solana accounts, built on the [CAIP-122](https://github.com/ChainAgnostic/CAIPs/blob/main/CAIPs/caip-122.md) standard. It builds and signs chain-agnostic sign-in messages, verifies them on your backend with single-use nonces and cookie sessions, and tracks the sign-in state in React, with no UI components and no hosted services.

---

## 🏛️ Where SIWX Fits in TUWA

TUWA is built in stages. Each stage builds on the ones below it, and SIWX sits at the bottom:

| Stage                          | Projects                                                                                                                  | Role                                                     |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| **1 — Core Auth & Primitives** | **SIWX**, [Orbit Utils](https://orbit.docs.tuwa.io/)                                                                      | CAIP-122 authentication and multi-chain primitives       |
| **2 — State & Connection**     | [Satellite Connect](https://satellite.docs.tuwa.io/), [Pulsar](https://pulsar.docs.tuwa.io/)                              | Wallet connection state machine and transaction tracking |
| **3 — Backend & Sync**         | [Quasar Cloud](https://docs.tuwa.io/quasar) or self-hosted [Quasar Community](https://github.com/TuwaIO/quasar-community) | Transaction indexing and cross-device sync               |
| **4 — User Interface**         | [Nova UI Kit](https://stories.tuwa.io/)                                                                                   | React design system and components                       |

SIWX depends on nothing else in TUWA. Higher layers use it (for example, Satellite Connect and the TUWA SDK), never the other way around. You can also use SIWX on its own in any app.

## 🧭 Principles

1. **One standard for every chain:** messages follow CAIP-122 (the EIP-4361 text layout), with CAIP-2 chain IDs such as `eip155:1` and CAIP-10 accounts. EVM and Solana use the same flow, types and backend routes.
2. **Headless and framework-agnostic:** no CSS or UI components. The core and server packages are plain functions and use Web APIs (`Request`, `Response`, Web Crypto); React bindings live in their own package.
3. **Modern Web3 libraries only:** `viem` and `@wagmi/core` for EVM, `@solana/kit` and Web Crypto ed25519 for Solana. No `ethers.js`, `web3.js`, `@solana/web3.js` or `gill`.
4. **Your backend, your data:** there is no hosted authentication service. Nonces and sessions live in stores you provide (Redis, SQL, KV…), and wallets stay with the user.
5. **The server decides:** the client state is for the UI only. Sessions are `HttpOnly` cookies checked on the server, nonces are single-use, and every verifier documents what it checks.

## 🔐 How a Sign-In Works

```
Browser (@tuwaio/siwx-react)            Wallet            Your backend (@tuwaio/siwx-server)
  │── GET /api/siwx/nonce ───────────────────────────────────▶ issue nonce (SiwxNonceStore, 300 s)
  │◀─ { nonce } ────────────────────────────────────────────── │
  │── buildMessage(fields) ─────────▶ sign (EIP-191 / ed25519)  │
  │◀─ signature ─────────────────────│                          │
  │── POST /api/siwx/verify { message, signature } ──────────▶ verify policy + signature,
  │                                                            consume nonce, create session
  │◀─ session JSON + Set-Cookie (HttpOnly) ─────────────────── │
  │── useSiwxSession(): authenticated                          │
```

The message the wallet signs:

```text
app.tuwa.io wants you to sign in with your blockchain account:
eip155:1:0xAb5801a7D398351b8bE11C439e05C5B3259aeC9B

Sign in to TUWA.

URI: https://app.tuwa.io
Version: 1
Chain ID: eip155:1
Nonce: 3f9c1e2a7b4d8f6051c2e9a0d7b3f418
Issued At: 2026-09-26T10:00:00.000Z
Expiration Time: 2026-09-26T10:10:00.000Z
```

## 🧩 Packages

| Package                                        | Layer | Provides                                                                                                        | Peer dependencies                                                                                                |
| ---------------------------------------------- | ----- | --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| [`@tuwaio/siwx-core`](/packages/siwx-core)     | L1    | CAIP-122 build, parse and validate; verification policies, session matching, nonces, errors and types           | `@tuwaio/orbit-core` ≥ 0.5                                                                                       |
| [`@tuwaio/siwx-evm`](/packages/siwx-evm)       | L2    | EVM signer, EIP-191 (EOA), EIP-1271 and ERC-6492 (smart contract wallet) verification                           | `@tuwaio/siwx-core`, `@tuwaio/orbit-core`, `viem` ≥ 2.18.6, `@wagmi/core` ≥ 3                                    |
| [`@tuwaio/siwx-solana`](/packages/siwx-solana) | L2    | Solana signer, ed25519 verification with Web Crypto                                                             | `@tuwaio/siwx-core`, `@tuwaio/orbit-core`, `@solana/kit` ≥ 8.2, `@wallet-standard/base` ≥ 1.1.1                  |
| [`@tuwaio/siwx-react`](/packages/siwx-react)   | L2    | `useSiwx` and `useSiwxSession` hooks, persisted zustand session store, Satellite Connect helpers                | `@tuwaio/siwx-core`, `@tuwaio/orbit-core`, `react` ≥ 19.2.3, `zustand` ≥ 5, `immer` ≥ 11                         |
| [`@tuwaio/siwx-server`](/packages/siwx-server) | L2    | Server verification, nonce and session stores, cookies, Next.js App Router handlers, JWT/JWKS for external auth | `@tuwaio/siwx-core`, `@tuwaio/orbit-core`; optional: `@tuwaio/siwx-evm` ≥ 0.5, `@tuwaio/siwx-solana`, `viem` ≥ 2 |

Each package page shows the package README followed by a reference of every export, generated from the TypeScript source.

## 💾 Installation

Install the core package and the L2 packages your app needs:

```bash
# L1 core
pnpm add @tuwaio/siwx-core @tuwaio/orbit-core

# L2 EVM
pnpm add @tuwaio/siwx-evm @tuwaio/siwx-core @tuwaio/orbit-core @wagmi/core viem

# L2 Solana
pnpm add @tuwaio/siwx-solana @tuwaio/siwx-core @tuwaio/orbit-core @solana/kit @wallet-standard/base

# L2 React
pnpm add @tuwaio/siwx-react @tuwaio/siwx-core @tuwaio/orbit-core react zustand immer

# L2 Server
pnpm add @tuwaio/siwx-server @tuwaio/siwx-core @tuwaio/orbit-core
```
